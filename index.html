Prismas, cubos y esferas

App de fórmulas y ejercicios sencillos para 2º ESO

Prismas

Un prisma tiene dos bases iguales y paralelas. Sus caras laterales son rectángulos o paralelogramos.

Área lateral = P · h
Área total = Área lateral + 2 · Área base
Volumen = Área base · h
P = perímetro de la base · h = altura del prisma.

Cubos

Un cubo es un prisma especial: todas sus caras son cuadrados iguales.

Área de una cara = a²
Área total = 6a²
Volumen = a³
a = arista o lado del cubo.

Esferas

Una esfera es un cuerpo redondo. No tiene caras planas, aristas ni vértices.

Área = 4πr²
Volumen = (4/3)πr³
r = radio. Puedes usar π ≈ 3,14.
