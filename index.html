Geometría 2º ESO

Prismas, pirámides, troncos de pirámide y fórmulas de áreas

Prismas

Tienen dos bases iguales y paralelas. Las caras laterales son paralelogramos.

Área lateral = P · h
Área total = Área lateral + 2 · Área base
Volumen = Área base · h

Pirámides

Tienen una base poligonal y caras laterales triangulares que se unen en un vértice.

Área lateral = P · ap / 2
Área total = Área lateral + Área base
Volumen = Área base · h / 3

Troncos de pirámide

Se obtienen al cortar una pirámide por un plano paralelo a la base.

Área lateral = ((P + P') / 2) · ap
Área total = Área lateral + Área base mayor + Área base menor

Pitágoras

Sirve para calcular apotemas, alturas y diagonales cuando aparece un triángulo rectángulo.

c² = a² + b²
Diagonal ortoedro: d² = a² + b² + c²
